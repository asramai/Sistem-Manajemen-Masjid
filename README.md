# Sistem Manajemen Masjid

Aplikasi web untuk mengelola operasional Masjid Pohuwato, mencakup presensi sholat, laporan gaji, manajemen pengguna, dan rekap kehadiran petugas.

## Tech Stack

- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [React Router](https://reactrouter.com/)
- [Supabase](https://supabase.com/) *(akan diintegrasikan untuk auth & database)*

## Fitur

- Input Presensi Petugas Sholat
- Laporan & Rekapitulasi Gaji
- Manajemen Pengguna & Petugas
- Rekap Kehadiran Mandiri Petugas

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

## Deployment

Aplikasi ini siap di-deploy ke Vercel, Netlify, atau platform statis lainnya.
